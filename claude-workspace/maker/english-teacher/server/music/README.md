# Nhạc cho Cú Bông

Chép file nhạc vào thư mục này (.mp3 .m4a .ogg .wav .flac). **Tên file = tên bài** (vd `Baby Shark.mp3`, `Con cò bé bé.mp3`).
Bé nói "mở nhạc", "hát bài Baby Shark" → cô tìm theo tên (không phân biệt hoa thường/dấu) rồi phát; bài dài hơn 6 phút chỉ phát 6 phút đầu.
Đổi thư mục: biến môi trường `STLAB_MUSIC_DIR`. Nhạc này Tuan tự có quyền dùng (lớp học/gia đình), không lên git.
