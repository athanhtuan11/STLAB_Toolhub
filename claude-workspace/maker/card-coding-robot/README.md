# card-coding-robot

Robot lập trình bằng thẻ cho trẻ 4–7 tuổi: xếp thẻ lệnh → quẹt qua lưng robot → bấm Chạy → robot đi trên thảm ô vuông.
Không màn hình, đọc lệnh song ngữ Việt–Anh. ESP32 + RC522 + 2 × 28BYJ-48, vỏ in 3D PETG.

Trạng thái: Bước 0 (giao diện) – xem `design/brief.md`.
