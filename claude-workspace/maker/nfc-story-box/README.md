# nfc-story-box – Hộp kể chuyện Cú con

Bé đặt thẻ truyện lên Cú con → cú kể chuyện (tiếng Việt + tiếng Anh); nhấc thẻ ra → dừng. Không màn hình, không mạng.
Trẻ 3–6 tuổi. Bo ESP32-S3 + MAX98357A + RC522, truyện MP3 trên thẻ microSD, thẻ NFC NTAG213, vỏ in 3D PETG.

## Trạng thái
- 2026-11-26: Tuan chọn dáng A (Cú trên gốc cây) + bo ESP32-S3. GĐ1 bản giấy `hardware/BOM.md` + `wiring.yaml`; chờ mua linh kiện + đo RC522.

## An toàn
- Nguồn USB 5 V, không pin Li-ion. Âm lượng có trần (tai trẻ). Không chi tiết nhỏ rời.
