# Research Scout

Công cụ quét nguồn công khai theo watch.yaml và tạo tổng hợp hàng tuần. Chạy `python scan.py`, `python scout.py mark ID quan-tam`, hoặc `python digest.py`. Cấu hình DB bằng `STLAB_RESEARCH_DB`; fixtures dùng `STLAB_RESEARCH_FIXTURES`.

Tạo lịch Windows bằng `register-tasks.ps1`; hủy lịch bằng `register-tasks.ps1 -Unregister`.
